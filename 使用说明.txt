========================================
  资源搜寻器  ·  使用说明
========================================

【3.38.0 检查更新】
· 进入工具后后台检查GitHub正式发布；侧栏“检查更新”可随时手动检查。发现新版会显示版本说明，你可选择更新或暂不更新。
· 更新下载与校验成功后才关闭程序，保留用户名存档、站点、黑名单、网站登录及下载文件。当前搜索/下载会停止。新版启动检查失败时回退旧文件。
· 仓库现已公开：无需登录GitHub或填写访问令牌，即可检查和下载更新。更新窗口中的“私有仓库访问授权”可保持空白，不需要配置。
· 无网络、无权限、无正式版本等情况会提示无法检查，不会假报已经最新，也不影响继续使用当前版本。
· 本工具使用Release完整包更新，用户无需额外安装Git/Python。备份位于程序目录同级隐藏的.resourcefinder-update-*文件夹。确认新版稳定后可清理相应旧备份。

【3.37.4 关闭与闪退保险】
· 正常关闭工具时优先断开Agent；仍在等待工具回复的请求会收到明确停止信号。
· 工具闪退时已无法发送指令。新版配套助手会检查本机控制通道，连续连接失败或超时后停止自身及自己启动的搜索子进程，不再无限重连。空闲待命也适用。
· 请重新复制接入指令，让Agent重新获取新版control/helper和network/helper。已经下载的旧助手不会自动更新。未使用配套助手的Agent需自行遵守同样的停止规则，工具无法强制终止外部软件内的模型或云端请求。
· 控制通道采用短超时和有限重试；资源搜索的180秒请求超时保留。暂停、单轮完成或Agent正在慢速搜索，不等于工具退出。

【3.37.3 换词后查看是否真正开始搜索】
· “搜索未开始 · Agent 尚未领取”表示新任务还在工具队列；“任务已送达 · 待 Agent 确认”表示已交付但尚未收到确认。侧栏同时显示任务号、发送次数和最后取任务时间。
· 若Agent已回复完成或待命且停止执行，请点击“复制继续指令”，粘贴到原Agent对话中继续。会话及当前任务保留，不需要重新握手。未领取时不显示搜索中的动画。
· 工具不能主动唤醒已经结束的外部模型对话，也不会用单独心跳或普通自动采集冒充AI搜索；静默不代表已经退出。

【3.37.2 Agent先理解，再搜索和审核】
· 常规模式仍把你的输入原样交给网站。Agent模式由Agent理解原话，提取主题、条件和搜索词，再逐批审核相关性后回推；数量上限只统计符合需求的资源，不用无关结果凑数。
· 更新后重新复制接入指令。每个新任务及触底续搜任务都会携带同一套理解和审核要求；复制内容同步当前任务、状态、额度和平台约束。
· 已取消3.37.1“裸--serve自动采集即AI搜索”的默认路径。没有真正调用模型的后台脚本无法代替Agent理解；应让当前Agent持续处理任务，或使用已具备模型理解和审核能力的后台工作程序。
· 网络助手和站点适配器只提供联网及候选。工具不能自行唤醒已结束的外部模型，也不能保证所有模型都正确遵循指令；不能把“在线”当作“已正确理解”。

【3.37.0 持续接管与实时切换额度（后台程序须符合3.37.2的模型能力要求）】
· 已收到20条时，限制→无限：原任务继续补980条；无限→限制：若本批已收到150条，本轮立即完成，150条全部保留，等待下一轮。低于100条时继续补到100条。
· 已完成100条后切到无限，会派发剩余900条；不会要求重新握手。模式切换不会重置本批计数，也不会丢掉正在入界面的结果。
· 更新后请重新复制接入指令，让Agent配置带通用搜索工作脚本的常驻接管器。它会在本轮结束后继续等待并启动下一任务，暂停不会退出，主动断开才终止。只启动单轮脚本或回复“待命”不足以保持接管。
· 工具提供运行助手和动态任务文件，不含外部模型凭据；工作脚本需要新模型推理时须由Agent配置相应调用。工具无法单方面唤醒已结束的模型对话，不会用后台空心跳冒充正在执行。

【3.36.3 连续空页停止空转】
· 同一查询连续3个成功页无新候选、达到第50页，或整轮累计检查200页时，工具会停止对应检索。该限制独立于100/1000条资源额度，不保证任意关键词必定有足够资源。
· 其他未完成来源仍会检查；本轮受限结束时保留已有资源与Agent连接，底部显示“本轮检索已停止”，不会谎称网站已没有资源，也不会自动补足重启。再次向下滚动可重试，或更换关键词、来源。
· 更新后重新复制接入指令给Agent；新指令要求读取limited标志，同一来源顺序推进关键词，减少后台页面反复恢复。

【3.36.2 资源不足报告须核验（收尾边界已由3.36.3补充）】
· Agent报告已搜完时，工具会核对实际分页：仍有下一页、未检查来源或仍有搜索在运行时，不接受提前结束，不撤销当前任务，也不清除已有结果。
· Agent会收到completion_pending和下一步要求；下次轮询仍会拿到原任务和剩余数量。重复、不相关或筛选后为空，不等于平台已没有下一页。真正的末页和100/1000额度限制仍有效。
· 更新后请重新复制接入指令给Agent。它必须读响应继续执行，不能回复“待命中”后结束对话。工具无法直接替外部AI客户端发起新的模型调用；如果该客户端自己结束对话，需要在那边继续对话，工具会保留尚未完成的进度。

【3.36.1 换词后不再误报重新登录】
· 已登录YouTube后，Agent可以交替查询不同关键词并继续各自的下一页；查询切换不会覆盖其他关键词的续搜状态。
· 工具最多保留4个后台工作页。页面被回收后会复用当前本地存档的登录自动恢复，并跳过已返回的资源，不需要用户重复登录，也不会弹出同步搜索网页。
· 只有网站确实要求重新登录或验证账号/年龄时，才需要用户在官网登录窗口处理。
· Agent等待一段时间后仍可沿用有效接管授权请求工具搜索，不会再因心跳过旧被网络接口拒绝。

【这是什么】
一个本地的小工具：在你指定的几个网站（白名单）上同时搜索，
把结果排成一墙带封面的卡片。默认单击打开，右键可以复制网址、标题或封面。

【3.36.0 Agent持续接管与自动检测】
1. 已接管任务不会因为90秒没有请求、210秒没有进度或检测超过5分钟就自动撤销。工具定期检查状态，已有任务、结果和数量额度保留。
2. 更新后，重新复制一次接入指令给Agent。新版指令要求耗时搜索脚本通过工具运行助手启动；启动后自动登记搜索子程序，工具每2秒核对存活状态，用户不用另配插件。
3. 只检查运行助手登记的进程及创建标识，不扫描电脑上其他程序。没有接入助手时，工具无法知道任意外部Agent是否正在思考，只显示未收到近期活动并继续保留接管。
4. 运行助手退出、子程序结束或PID被复用后，不会继续当成搜索仍在运行。独立的取消监听器不算活跃搜索。用户点击断开、暂停、换词、改来源或达到额度时，原中断规则仍生效。
5. 连接详情中可看“工具网络累计”和“工具外等待/执行”。工具外时间包括Agent的规划、自行抓取、登录等待等，不等于纯模型思考时间。Agent应优先使用工具搜索接口及candidate_id，可靠元数据不必逐条重复打开资源页核实。

【3.35.2 YouTube触底续搜修复】
· 已登录搜索使用后台网页自己的加载流程，解决部分关键词只收到广告或假空页、反复触底仍没有新资源的问题。不会显示同步搜索网页，也不需要重新登录。
· 每次只加入新资源；失败或取消不记成成功页，重试可以重新读取。只有实际网页确认结束时，底部才显示没有更多资源。
· 3.35.1只修正了弹窗分类，没有解决手工登录续页请求不完整的问题；本版替换该续页实现。

【3.35.1 历史：触底重复登录弹窗修复】
· YouTube明确返回“无更多结果”等结束提示时，工具在底部显示该来源没有更多资源，不再误弹登录窗口，也不会反复触底请求同一页。
· 续页暂时异常或页面格式未知时，保留已显示的资源，可再次触底重试；只有网站明确要求登录/年龄验证时，才进入登录流程。

【3.35.0 登录一次，后台继续搜索】
1. 搜索YouTube遇到登录提示时，工具会打开专用Edge/Chrome登录窗口。在这个窗口自行完成官网登录或验证，然后回到工具点“已登录，继续搜索”。
2. 工具自动关闭专用登录窗口，后续搜索和触底加载在无界面后台完成，不再显示同步搜索网页。日常浏览器和正在观看的视频不会被接管。
3. 登录状态保存在当前本地用户名下，关闭重开工具后可自动复用；无需保持登录窗口打开，也无需安装扩展或粘贴连接信息。
4. 专用窗口与日常浏览器资料独立，首次需要在专用窗口登录一次。不同本地用户名分别登录。登录过期、网站风控或再次要求验证时，工具才重新提示。
5. 退出工具或切换存档会停止自有后台浏览器，保留登录资料。浏览器资料受Windows账号保护，复制工具到另一台电脑不保证沿用网站登录；不要分享自己的profiles目录。
6. 当前后台登录续搜适用于YouTube，其他平台及下载功能按各自原有支持范围工作。真实验收已通过两次触底24→45→64条，以及重启后直接搜索24条。

【3.34.0 筛选简化与可靠性检查】
· 搜索类型只在输入框下方选择：视频、图片、文章、音效。结果上方不再重复提供类型选项；来源独显、排序和其他筛选保留。
· 解析搜索语句时改词、清空或切换模式，旧解析不会再覆盖新操作或卡住搜索按钮。退出当前存档后也不会因迟到任务重新启动浏览器读取。
· YouTube部分续页没有返回封面字段时，提前补入对应公开视频封面地址，减少卡片等待补图。
· 交付目录不再放多版测试报告。profiles是用户存档，vendor和_internal是解压即用组件，不应删除。维护源码与当前文档保留，方便后续交接。
· 开发机历史测试、备份和无引用截图移到工具目录外的“资源搜寻器_开发归档”；这是移出归档，不是删除存档或下载文件，也不代表释放了同等磁盘空间。

【3.33.1 历史：默认登录方式以顶部3.35.0为准】
1. 点击“已登录”优先复用已经打开的同词YouTube搜索标签，不再额外打开浏览器窗口，也不重复加载同词页面。
2. 若你正在看视频，或把原搜索页点成了视频，工具会保留播放页，复用同一窗口中的搜索标签；没有时只准备一个后台搜索标签，然后恢复原来的播放页。后续触底继续使用搜索标签，不会每次创建新页。
3. 请保留搜索标签，读取时可能短暂切换标签或焦点。浏览器禁止后台播放时，工具不能保证播放完全不受影响。退出工具会保留浏览器页面，仅停止读取组件。无需安装扩展。

【3.33.0 历史：窗口复用以顶部3.33.1为准】
1. 网站提示登录时，你只需使用常用Chrome、Edge等Chromium浏览器在官网完成登录或必要验证，保持YouTube页面打开，再回工具点击“已登录，继续搜索”。
2. 工具会自行读取普通浏览器页面并建立自己的工作窗口，自动验证实际搜索、关掉登录弹窗并继续。本流程不用安装扩展、开发者模式、加载文件夹或粘贴连接信息。
3. 工作窗口使用原浏览器正常会话，不是内嵌或远程调试登录浏览器。程序不填密码/验证码，不导出Cookie、不修改浏览器安全设置。读取期间可能短暂切换焦点，请保留工作窗口。
4. 续搜优先通过页面访问接口后台滚动；取消或换词会中止读取组件。退出工具只关闭工具标记的YouTube工作窗口，日常浏览器窗口保留。若你在工作窗口改为其他网站，工具不会导航它继续搜索。
5. YouTube常规触底搜索增加新版Shorts和续页结构支持。仅非视频的中间段会有限跳过；请求失败保持页码可重试，未知页面不会当作“全站资源已搜尽”，可按提示用免扩展方式核对。
6. 本机真实Edge验证为24→35→59条。当前浏览器登录续搜仍主要支持YouTube；Firefox、企业禁止页面访问接口或较旧浏览器不保证可用，会显示具体失败原因。
7. 旧版浏览器连接助手及安装扩展页面不再是默认流程。已经安装的扩展可继续兼容使用，无需为新版默认流程额外配置或重新安装。

【3.32.0 历史：默认连接方式以顶部3.33.0为准】
1. 搜索YouTube遇到登录提醒时，使用你常用的Chrome、Edge等Chromium浏览器打开YouTube，自行完成登录或原站要求的验证，并保持页面打开。
2. 回到工具点击“已登录，继续搜索”。已有已授权会话会直接检查；需要连接时，工具会在正在运行的受支持浏览器中自动打开本机连接助手。无需复制、粘贴连接信息。
3. 首次使用仍需确认安装一次工具自带扩展：在助手中打开对应浏览器扩展管理，开启开发者模式，加载browser-extension文件夹。助手可复制完整目录。浏览器禁止外部程序静默安装扩展，工具不会更改安全策略。
4. 已装旧版扩展时，在扩展管理页重新加载新版文件夹，再刷新本机连接页面。安装/更新后连接自动完成，工具检查实际搜索页，确认可访问后自动关掉登录弹窗并恢复该平台搜索。
5. 连接与验证期间显示加载图标；默认连接等待约3分钟。失败显示原因并恢复“已登录”按钮，可重试。本轮跳过只跳过当前平台；切换关键词后旧进度不会重新弹窗或覆盖结果。
6. 多个浏览器或独立个人资料需要分别安装一次扩展；工具只检查已授权连接中的YouTube页面，不能读取任意浏览器的全部页面。当前不支持Firefox浏览器续搜。
7. 工具可以复用有效登录状态，但不能代替用户完成所有网站的首次账号登录、验证码、年龄确认或授权。其他平台仍按现有支持范围工作。

【3.31.1 视频时长补全】
· 视频时长显示在封面右下角，支持YouTube搜索页的不同角标/文本结构。
· Agent或索引提交的B站、YouTube视频没有时长时，工具会在后台尝试补全当前可见区域的时长，成功后自动显示，无需重新搜索。
· 已有时长不重复查询；切换搜索后旧查询不会改动新结果。图片、文章不会查询视频时长。平台限制、网络失败或直播没有可靠时长时不会编造数字。

· 首次启动会自动等待浏览器连接端口准备好。新窗口中的“正在连接资源页面”是加载提示，请等待同一次操作完成，不需要第二次点击。
· 失败原因直接显示在面板状态文字中，完整说明可将鼠标停在状态文字上查看。继续操作使用同一个“一键重试”按钮。

【3.30.1 历史：下载面板显示与浏览器复用】

【3.30.0 历史：爱给一键自动提取，无需安装扩展】
1. 右键爱给音效资源选择下载，点击面板中的“一键打开并提取”。
2. 工具会自行打开独立Edge窗口（没有Edge时尝试Chrome），加载这条资源、点击正常播放按钮并识别音频地址。无需安装扩展或粘贴连接信息，也不用等待整段播放完。
3. 识别成功后回到工具选择格式、目录，加入下载队列。下载开始时会再次识别限时地址，并校验文件时长、完整解码和实际音质。
4. 独立浏览器不读取你日常浏览器的登录信息；网站要求登录或验证时，请在新窗口自行完成，工具会继续等待，默认最长3分钟。未完成可再次点击一键提取重试。
5. 关闭下载面板可取消本次解析；退出工具或切换本地账号会关闭工具自己的独立浏览器，其资料保存在当前本地存档内。
6. 如需使用常用浏览器，旧扩展方式保留在“使用常用浏览器扩展（可选）”中，默认折叠。YouTube原扩展搜索流程保持不变。
7. 修复详情页播放器漏识别。实际验证“下雨声”和“吃饭的声音”可自动播放提取；受网站、网络、账号及页面变化影响，不能保证所有资源均成功。
8. 保存的是网页播放版本，非原始无损素材；不会自动购买、处理验证码、修改试听限制或启动录音。

【3.29.0 历史：爱给音频播放版直接提取】
1. 在爱给音效卡片上右键选择下载。公开页面有音频地址时仍可直接解析；动态播放器需要连接浏览器。
2. 解析提示需要浏览器时，点击“扩展文件夹”，按其中说明安装；已安装的用户在扩展管理页重新加载更新后的扩展。
3. 打开扩展弹窗，点击“启用爱给播放提取”，自行确认浏览器的站点访问提示。该权限可选，不影响YouTube或其他资源搜索。
4. 在工具点击“复制浏览器连接信息”，粘贴到扩展并连接。工具或浏览器重启后需要重新连接。
5. 点击“打开资源网页”，在原站正常播放目标资源一次，等播放器开始播放后回到工具点击“重新解析”。无需等待整段播放完毕。
6. 选择保存格式和目录后加入下载队列。默认保留播放文件、不重编码，也可转换MP3/M4A/WAV/FLAC。
7. 文件名标注[网页播放版]；保存前检查音频轨道、时长与完整解码，下载中心显示实际音质。播放版可能经过压缩，不是原始无损文件；转成WAV/FLAC也不会提升源音质。
8. 资源不匹配、试听长度受限、地址失效或文件不完整时明确失败。地址失效请刷新资源网页、重新播放，再重新解析或重试下载。不调用MCP付费下载，不会启动录音或自动播放。
9. 当前真实样本验证为14.70秒和149.87秒、64kbps/22050Hz；不保证所有资源、账号或网站布局适用。更新扩展后请按本流程启用站点权限。

【3.28.0 爱给网页提取与MCP只读查询】
· 爱给MCP只用于搜索和获取资源信息，不再调用官方文件下载或预览下载接口。下载面板已移除MCP登录入口、报价和铜币确认。搜索/详情可能使用官方查询额度。
· 在爱给视频、图片或音效封面上点右键，选择“下载资源”，工具会尝试从公开网页提取已有媒体地址。无需为下载先授权MCP。选择提取版本、格式和保存目录后加入下载队列。
· 已验证视频预览、图片预览可保存；视频支持MP4/MKV，图片保持网页格式。如果页面提供可读取的音频文件地址，可保留格式或转为MP3/M4A/WAV/FLAC。完整音效原文件当前尚未验证成功，缺少可用地址时会明确说明。
· 预览可能低清、缩短或带水印，面板会标明版本，保存文件带“[网页预览]”。普通网页文件也会标记完整性未确认，不宣称为原始素材；不会自动变成高清原件或完整音效。
· 下载开始前会重新解析网页以刷新限时地址；页面版本变化时请重新解析，工具不会用相似标题的其他资源代替。
· 旧版爱给待授权任务需要从封面重新解析，不继续旧下载通道；已保存文件不会删除。其他平台下载不受此变化影响。
· 如希望使用MCP查询信息，仍可进入“设置 → 素材连接 → 爱给官方MCP”，在自己的浏览器完成授权。该授权和网页下载互相独立。

  连续三次补足没有新增时自动暂停并提示，向下滚动可重试剩余数量，避免无效循环消耗 token。

【怎么用】

0. 先解压整个文件夹，双击里面的「资源搜寻器.exe」。
   ⚠ 不要把 exe 单独拷走：旁边的「_internal」文件夹是程序的一部分，
     两者必须放在一起，否则打不开。

1. 双击「资源搜寻器.exe」打开（文件夹版直接启动，不用等解压）。

2. 直接搜索时，在底部输入框输入想找的内容，按回车或点「开始搜索」。
   Agent 模式先复制接入指令并完成接管，输入框才会开放（见文末 3.0.0）。

3. 结果会一张张出现在右边：
   - 打开“站点管理”，列表里的「+23」表示这个站抓到了 23 条；
   - 如果某个站显示红色的「✕」，把鼠标放上去能看到原因。

4. 单击卡片（点封面也算）= 直接用浏览器打开这个视频，屏幕下方会弹
   「已在浏览器中打开」；万一系统没唤起浏览器，会提示检查默认浏览器，
   可以主动右键复制链接，再粘贴到浏览器。不会自动覆盖剪贴板。
   右键卡片 = 在浏览器中打开 / 复制网址 / 复制标题 / 复制封面图
   （复制成功会在屏幕下方弹「已复制…」提示）。
   只想拿链接、不想打开时，就用右键「复制网址」。
   封面左上角是**发布日期**（今天 / 3 天前 / 09-14），右下角是视频时长。

5. 搜过的词会记在「历史」里，下次点一下就重搜。

6. 「开始搜索」旁边有个 **⟳ 刷新按钮**：按当前关键词和筛选条件再搜一次，
   用来刷新结果（比如刚才某个站失败、或者想要更新的内容）。
   正在搜的时候点它，会先停掉当前这轮，再自动重新搜。

7. 结果区上方有四个筛选：
   排序（相关度/最新发布/播放最多）、时间（不限/24 小时/本周/本月/今年）、
   播放量（不限/1 万/10 万/100 万）、按来源分组。
   封面是滚到哪下到哪：往下滚，下面的封面才会加载。
   滚到最底下会自动去抓下一页，一直往下滑就行；某一轮没有新结果时
   状态栏会显示「已经到底了：共 N 个资源」，说明这个关键词搜完了。


【两种模式】左侧导航可以切换

· 直接搜索（默认）：输入关键词，直接去白名单站点抓。

· Agent 模式：让本机已经开着的 AI Agent 接管搜索。
  工具**不会自动扫描**你电脑上装了什么，全靠你用「复制 → 粘贴」把它接上。
  1) 左侧点「Agent 模式」→ 出现「收件口」提示条（默认已开启），
     上面有地址：http://127.0.0.1:端口/api/results?token=xxxx
  2) 点「① 复制接入指令」，把剪贴板里的内容粘给你本机的 Agent
     （WorkBuddy / Claude Code / Codex / DSH / Cursor 这类能执行命令的，
     在它的对话框里粘进去、回车即可）。
     Agent 收到后会开始「循环取任务」：GET /api/task?token=...
  3) 之后你在输入框里用大白话说想要什么，点「AI 搜索」：
     - 有 Agent 在循环取任务 → 任务直接派给它，由它去搜、去筛，
       搜完把结果 POST 回来，卡片立刻出现在列表里；
     - 还没有 Agent 接入 → 会弹窗提醒，不会偷偷用关键词搜一份。
       弹窗里三个选择：
         · 「我已粘贴，交给 Agent」= 保留任务，等你把剪贴板粘过去
         · 「仍用本地搜索」= 明明白白地按关键词搜（会提示这不是 Agent 结果）
         · 直接关掉 = 取消，什么也不做
       弹窗里的「重新检测」可以现场复查 Agent 有没有接上。
  4) 提示条上会显示「等待 Agent 接入」或「<Agent 名字> 正在接管（N 秒前取过
     任务）」——能看到到底是哪个 Agent 在干活（它取任务时会在地址里带上
     自己的名字，比如 &agent=WorkBuddy）。
     点「AI 搜索」后，**左边侧栏**会出现转圈的「正在让 X 搜索…」，
     不会挡住结果区；期间不要反复点（再点也只会提示你它在忙）。
     提示条右边的「⏸ 暂停」可以随时停手：暂停后 Agent 拿到任务会看到
     paused=true 自己停下、推来的结果也不再入库；点「▶ 继续」接着搜。
  5) 多个 Agent：如果又粘了一份指令给另一个 Agent，新来的会接管，
     旧的会收到「已被接管，请停止」的回复并退出；界面上的名字也跟着换。
  6) 一直往下滑 = 一直搜：滚到最底下会自动派一条「要更多」的任务
     （带上已经给过的链接让它跳过），限制模式每批最多 100 条，之后等待滚动；
     无限模式自动分批续搜，每个关键词累计最多 1000 条，资源不足时提前结束。
     Agent 是**边搜边推**的：搜到一条就先发一条，卡片一张张冒出来，
     侧栏显示「已收到 N 条，Agent 还在继续搜…」，不用等它全搜完。
  7) 换搜索词：**就算上一轮还在搜，也会立刻中断**，先清空旧结果，
     再按新词重新派任务，不会混在一起、也不用等它搜完。
  8) Agent 搜不到/被审核拒绝/报错时，它必须调 POST /api/error 上报；
     工具会**弹窗告诉你它报的是什么错**，并结束「搜索中」状态。
     如果它既不回话也不报错，连续 150 秒没有结果或进度后工具会弹「等待 Agent 超时」。
  9) 收件口只监听本机 127.0.0.1 并带 token，外网访问不到。

· 黑名单：两种模式下都生效。关键词里有黑名单词会被拒绝搜索；
  Agent 推回来的结果也会按标题/简介/链接/作者过滤一遍再展示。


【站点管理与黑名单管理】

点击左侧对应管理按钮打开窗口，下列列表仅在窗口内展示；修改会即时保存，点“完成”或关闭窗口收起。

· 站点 = 白名单：这些网站会被搜索。
  - 勾选框：取消勾选就不搜这个站；
  - 双击一行：修改它（名称、搜索地址、代理方式、抓取条数）；
  - 「添加站点」：粘贴网站链接添加自己的站点；
  - 「删除」：把选中的站从名单里去掉（内置的也能删）；
  - 「恢复默认」：把内置的 4 个站点找回来（会覆盖当前名单）。

  内置的 4 个站（哔哩哔哩 / YouTube / 必应网页 / 百度视频）也可以随便改：
  - 只改名字：还是用原来的搜索方式；
  - 改「搜索地址」：它就变成普通网页站，按你填的地址抓；
  - 改坏了：选中它点「恢复默认」，四个内置站就回来了。

· 黑名单：禁止搜索的内容。
  - 输入词，回车加入；
  - 搜索的关键词命中黑名单 → 直接拒绝搜索；
  - 结果里标题/描述/网址含黑名单词 → 自动过滤掉。

· 网络检测：
  - 程序**每次打开会自动检测一次**（左下角徽标会从「检测中…」变成结果），
    不用手动点。
  - 想手动重测，点左下角「⟳ 刷新网络」：重新检测本机的 VPN / 代理状态，
    并让程序按当前网络配置访问。点一下会显示三行：
    系统代理：开 → 127.0.0.1:端口（或者「系统代理：关（直连）」）
    国内 ✅ · 境外 ✅（代理 1.0s）  ← 括号里是实际走通的通道和耗时
    再下面一行是说明文案（比如「系统代理已关闭…境外站点访问不了，这是正常的」）。
  判断依据是 Windows 的「系统代理」开关，跟浏览器完全一致：
    - 你开了 VPN（代理软件会打开系统代理）→ 这里就 ✅，搜索也能上外网；
    - 你关了 VPN（系统代理被关掉）→ 这里就显示境外 ❌，程序也不再偷偷
      走后台上网的通道，跟你的浏览器表现一样。
  它会把代理和直连都试一遍：代理能通就用代理，代理通不了就自动改直连。
  如果你用的是 TUN / 虚拟网卡模式，系统代理没开但直连确实能上外网，
  这里也会显示 ✅，并注明「可能开着 TUN / 全局代理」。


【加自己的网站】

点“站点管理 → 添加站点”，在“网站链接”粘贴一个首页、视频页或文章页网址。
工具自动识别所属网站并预览搜索地址，名称会自动填写，也可以自行修改，再点“保存”。
例如粘贴 B站 /video/BV... 链接，会采用 https://search.bilibili.com/all?keyword={q}，不局限于这一个视频。
其他网站优先识别其公开搜索表单，找不到时用限定域名的视频检索；不需要用户了解网址语法。
如果已有准确的搜索模板，也可直接填写，例如 https://www.example.com/search?word={q}&page={page}。

如果自动识别抓不准，展开「高级」填 CSS 选择器：
  结果条目选择器：每个结果的外层容器，如 li.result
  链接选择器：    a
  标题选择器：    h3
  封面选择器：    img

填完点「▶ 测试抓取」可以当场看能抓到几条。
提示：需要浏览器跑 JS 才显示内容的站（如知乎搜索）抓不到；
      芒果TV、抖音这类纯前端渲染的站也不行。


【设置（右上角齿轮）】

· 网络：自动 / 代理优先 / 只走直连。默认「自动」会跟随系统代理。
        YouTube 在国内需要代理；B 站、必应会优先直连。
· 抓取：同时搜几个站、每个站最多几条、超时、请求间隔。
· 显示：深色/浅色主题、是否显示封面、点卡片时复制还是打开。
· 封面缓存：占多少磁盘、一键清空。


【常见问题】

Q：某个站一直 0 条？
A：B 站短时间内搜太频繁会触发风控，界面会提示；等半分钟再试。
   YouTube 需要开代理。

Q：封面显示「无封面」？
A：图床防盗链或网络问题；可以设置里关掉封面显示，或清空缓存重试。

Q：链接复制了但打不开？
A：百度/必应的跳转链接会在复制后自动解析成真实地址，状态栏会提示
   「已解析」。如果没解析成功，可在浏览器里打开一次，它会自己跳转。

Q：配置在哪里？想重来怎么办？
A：%APPDATA%\ResourceFinder\config.json
   删掉这个文件就恢复默认设置。
   （如果该目录不可写，会存在 exe 旁边的 data\config.json）

Q：会上传我的搜索记录吗？
A：不会。所有请求都是本机直接发往各个网站，配置、历史、缓存只存本机。


Q：为什么是文件夹而不是单独一个 exe？
A：单文件版每次启动都要把程序解压到系统临时目录，个别电脑的临时目录
   被安全软件锁住，会弹「Could not create temporary directory!」。
   文件夹版不依赖临时目录，启动还更快，所以改成了文件夹版。

Q：启动报错 / 打不开？
A：先确认 exe 和 _internal 文件夹在同一个目录里（别只拷 exe）；
   还不行的话，把 exe 所在目录整个换到 D 盘再试一次。


【卸载】
删除整个文件夹即可；再删掉 %APPDATA%\ResourceFinder 和
%LOCALAPPDATA%\ResourceFinder 两个文件夹，就一点不剩了。

【文件夹里还有什么】

【3.0.0 当前操作：接管确认与 Agent 外网检测】
升级后请务必重新点击“复制接入指令”，把最新指令粘给 Agent。
1. 左侧切到 Agent 模式，此时输入暂不可用。点击“复制接入指令”后会出现接管等待窗口。
2. 切到你的 Agent 对话粘贴并发送。工具依次显示：等待请求、等待握手确认、等待再次轮询。
3. Agent 确认并再次取任务后，窗口自动关闭，输入框开放。无需自己判断“是不是好了”。
   等待超过 120 秒仍未接管会提示重试。可重新复制指令，或返回直接搜索；不会把超时当作成功。
4. 首次需要外网时，工具给 Agent 交付检测目标、当前代理配置和可审阅的网络助手。
   Agent 实测：有当前代理时优先代理，再尝试直连、工具本地中转。通过后才开始搜索并回推。
   助手只使用 Python 标准库；没有 Python 时 Agent 也可按接口自行测试并报告。不会安装插件。
5. 若工具能访问外网而 Agent 无法使用代理端口，可由 Agent 调用本机中转获取网页或搜索候选资源。
   这不会自动改变 Agent 的内置云端联网工具；后续请求需使用已验证的代理或中转通道。
6. 所有通道失败，界面会弹出具体失败报告。150 秒没有进度/报告，或检测总时长超过 5 分钟，
   会停止本次任务并说明原因。可以调整当前网络后重试，或换 Agent。
7. “连接详情”里可查看 Agent 外网状态和通道，悬停查看检测记录。
   成功通道缓存 15 分钟；换 Agent、代理配置变化、缓存到期或任务失败后重新检测。
8. 不涉及登录、用户 API 配置或修改 Windows 系统代理。若 Agent 自身禁止命令执行或网络访问，
   工具无法解除这些权限限制，会要求 Agent 如实报告。工具也无法自动唤醒已结束的 Agent 对话。
此前版本关于“输入后再接管”的说明，以本节为准。直接搜索、封面打开、右键复制保持原样。

【3.3.0 限制模式 / 无限模式】
Agent 操作栏新增“搜索额度”切换，默认限制模式，选择会保存供下次启动使用。
限制模式：一次最多接收 100 条，停止后不再自动续派；向下滚动到底部才搜索下一批最多 100 条。
当结果较少、页面没有滚动条时，在结果区域继续向下滚动即可加载。布局变化不会自动触发新批次。
无限模式：工具自动分批续搜，但每个关键词累计最多 1000 条，到达上限后停止。此时滚动
不会再搜索；换关键词或明确开始一轮新搜索才重新计数。资源不足时可以提前结束，不强行凑数量。
切换模式会立刻取消当前批次，保留已有结果和当前关键词的已用数量；切回限制模式后等待你主动加载。
额度按去重后的有效回推链接计数；重复/无效链接不占额度，黑名单或筛选可能使可见卡片少于额度。
工具端会截断超量回推并取消已满额任务，Agent 应停止本轮子搜索；不能只在界面隐藏超出部分却继续搜。
升级后请重新复制最新指令给 Agent。数量限制能阻止工具持续派发搜索，但不等于服务商的 token 计费上限。

继续按钮仍要求新的轮询确认才续搜。明确断开 Agent 仍立即撤销连接，必须重新接入。

【3.9.2 Agent 暂停、恢复与失联（历史；连接提示由 3.9.3 修正）】
升级后请重新复制接入指令并发送给 Agent，让它使用新版暂停规则。
暂停只停止本轮搜索；Agent 应继续以 wait=20 长轮询等待，不能因为 paused、task:null 或子任务取消而结束接管。
点击“继续”后，工具先等待 Agent 的新取任务请求，确认仍在运行后才派发续搜任务。
暂停或空闲超过 45 秒未取任务，会显示“Agent 已失联”，停止等待并保留已收集的结果。
此时重新发送接入指令；确认接入后再点“继续”或输入新关键词。暂停期间也可以完成重新接入。
工具不能自行启动或唤醒已经结束的外部 Agent；如果对方受执行时长或会话限制退出，需要在其对话中重新接通。

【3.9.1 海外视频封面修复】
YouTube 等站点返回 AVIF 格式封面时，工具自动在后台转换并显示，解码组件已包含在程序内。
单张封面损坏或不存在，不再导致整个图片服务器被跳过；网络故障的冷却也不会因继续滚动而无限延长。
关闭旧程序后重新打开原目录的“资源搜寻器.exe”即可生效，现有配置和历史保留，无需另装组件。
直接搜索与 Agent 模式都适用；真实网络断开或站点拒绝访问时，仍需要恢复可用的网络连接。

【3.9.0 连续分页与到底提示】
1. YouTube、百度视频已接入真实续页接口；必应按站点返回的位置翻页，保留页内余量，避免重复取首屏。
2. 选中来源后，向下滚动到底，只继续加载当前选中的搜索来源。切换来源保留各自进度。
3. 站点明确返回末页或无结果标记时，底部会显示“平台名称：当前关键词下没有更多资源了”，并弹出一次提示。
   其他未结束的平台仍可继续搜索。这表示当前查询在该站点可返回的结果结束，不代表全网所有视频均已找到。
4. 网络失败：保留页码，再次触底重试；重复或被筛选：可再次触底继续；未配置分页：明确提示不支持。
   必应遇到重复页最多自动向后检查三页，仍重复会提示实际情况，不会无限请求，也不会谎报没有更多。
5. 必应、百度视频属于聚合搜索来源，来源菜单会标注“搜索来源”。它们找到的视频也可出现在实际播放平台下，
   但同一个视频只展示一张卡片。来源数量可重叠，不相加作为总资源数。
6. Agent 使用工具的 network/search 时会收到 pagination.exhausted（true/false/null）、supported 和 message。
   true 才表示明确结束；失败、重复或被筛选不能当成结束；请保持人工接管流程与原有额度上限。
