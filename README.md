# 资源搜寻器 · Resource Finder

一款 Windows 本地资源搜索与下载工具，将多个网站的搜索结果集中展示，方便查找、筛选和保存视频、图片、文章及音效。

## 主要功能

- **四类资源搜索**：按视频、图片、文章（含小说）或音效选择搜索模式。
- **多站点检索**：支持哔哩哔哩、YouTube、Pixiv、爱给网等来源，可管理参与搜索的站点，也可粘贴网址识别并添加站点。
- **直接搜索与 Agent 模式**：直接按关键词检索，或接入外部 Agent 理解需求、组合搜索词并返回资源；支持切换任务、暂停和断开接管。
- **筛选与连续浏览**：按来源、发布时间等条件筛选，支持单独查看某个平台；向下滚动加载更多。Agent 模式可选择每批最多 100 条或每个关键词最多 1000 条。
- **资源卡片**：集中显示封面、标题和来源，提供网站返回的作者、时长、播放量等信息；点击封面打开原网页，右键复制资源链接。
- **资源下载与下载中心**：支持部分平台的视频、图片、文章和音效下载。视频可按可用资源选择完整视频、仅画面或仅音频，以及清晰度、格式和保存位置；下载中心可查看进度、重试任务和清除记录。
- **本地用户名存档**：不同用户名分别保存站点、黑名单、设置和搜索历史，随工具目录保存，可退出并切换存档，无需联网注册。
- **站点与黑名单管理**：站点和屏蔽词收纳在管理窗口中，避免直接展示在主界面。
- **网络与网站登录**：支持网络检测及代理配置；需要登录的平台可通过专用窗口完成登录，支持后台复用对应会话。
- **可选版本更新**：启动时检查新版本，也可手动检查；用户自行决定是否更新，升级保留本地存档。更新源无法公开访问时会明确提示，限流和网络异常单独说明。

搜索和下载能力取决于各网站实际提供的资源、访问权限及登录状态；不是所有网站都支持相同功能。

## 使用

下载 Windows 版本，完整解压后运行 **资源搜寻器.exe**，无需额外安装 Python 或 Git。不要单独移动 exe，运行组件需与程序放在一起。
