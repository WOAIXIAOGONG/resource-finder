# 资源搜寻器（Resource Finder）

一个本地的「一键找资源」小工具：在内置/自建的白名单站点上同时搜索，把结果排成一墙带封面的
卡片，点一下卡片直接用浏览器打开，右键可以复制网址 / 标题 / 封面图。

源码与更新发布：https://github.com/WOAIXIAOGONG/resource-finder （私有仓库，需要访问权限）

## 3.38.0：GitHub 私有发布与可选更新

- 启动后后台检查正式 Release；侧栏“检查更新”可随时手动检查。发现新版后可选择下载更新或暂不更新，不会强制升级。
- 下载校验 GitHub SHA256 与完整文件清单，确认后退出工具并更新；启动检查失败回退旧程序。保留 profiles、站点配置、网站登录、data 与 downloads，以及程序目录中的其他非托管文件。
- 私有仓库只允许有权限的账号检查和下载。其他用户需先获仓库访问权限，再在“私有仓库访问授权”填写只读 Contents 令牌；令牌使用 Windows DPAPI 加密保存在当前电脑用户目录，不进入Git或ZIP，不分发作者账号密码或令牌。
- 成品更新使用 Release 安装包，无需 Git/Python 环境。源码仓库不包含运行环境、存档、下载记录、截图或凭据；这些运行组件随Release ZIP提供。
- 更新时保存当前配置并停止搜索/下载，安装后重新打开工具。更新备份在安装目录同级的隐藏 `.resourcefinder-update-*` 文件夹；新版本稳定后可清理对应旧备份。

### 后续开发与发布

开发者首次克隆 `git clone https://github.com/WOAIXIAOGONG/resource-finder.git`；已有源码可用 `git pull --ff-only`，有本地修改时先自行提交或暂存，成品目录不要直接 git pull。
安装requirements后，运行tools/fetch_download_tools.py获取官方便携组件，tools/build_browser_reader.py构建读取组件。按AGENTS.md完成改版、测试、独立构建、package.py打包（生成update-manifest.json）。提交并push源码，再运行：

```powershell
python tools/publish_release.py --zip dist/资源搜寻器-v版本-win64.zip --publish
```

需安装并授权GitHub CLI。发布脚本先创建草稿、上传ZIP并核对GitHub摘要，通过后才公开为仓库内正式Release；不覆盖旧版本。更新用户需要读取权限，发布者需要写入权限。访问仓库失败不等于“已经最新”，工具会明确报告无法检查。

## 3.37.4：工具退出与闪退的停止保险

- 正常退出优先撤销Agent会话，仍在等待的接口收到停止信号，再清理下载和浏览器。
- 闪退无法主动发消息。配套运行助手通过独立的短超时控制检查发现服务持续不可达，终止自己启动的搜索子进程树并输出不可重试的会话结束信号；空闲轮询也会停止。
- 更新后重新复制接入指令，让Agent重新获取新版助手。未使用助手的外部Agent必须自行遵守检查与停止规则；工具不能强制结束其他软件的模型思考或已经发出的云端调用。
- 本机控制检查与资源请求超时分开：控制GET最多3次、每次约4–6秒；资源搜索仍可等待180秒。暂停、单轮完成、正常慢搜索不会因此结束接管。

## 3.37.3：换词后的任务领取状态与继续执行

- 新任务未领取时明确显示“搜索未开始 · Agent 尚未领取”；送达但尚未确认时显示“任务已送达 · 待 Agent 确认”，并显示任务号、发送次数及最后取任务时间。
- Agent已经回复完成/待命并停止执行时，点击“复制继续指令”发送给原Agent。会保留会话和当前任务，无需重新握手；实际恢复取任务并确认后才显示执行中。
- 工具不能唤醒已结束的外部模型对话，静默也不能证明对方已经退出；不会以空心跳或无模型采集冒充AI搜索。

## 3.37.2：Agent先理解，再搜索和审核

- 常规模式保留原样搜索。Agent模式的query是用户原话，必须由Agent识别目标、生成检索词、审核候选相关性后再回推；不能把自动采集当作AI理解，也不能为凑100/1000条接收无关结果。
- 复制入口、HTTP帮助和每个search/more任务共享同一套职责。快照显示最新状态、剩余额度及平台约束，用户原话作为JSON字符串数据保留。
- 取消3.37.1的裸`--serve`默认采集：没有模型工作程序时应由当前Agent持续处理；只有已具备真实模型调用及审核的程序才可用`--serve --run`后台调度。网络通道和运行助手本身不具备模型能力。
- 更新后需重新复制新版指令。工具不能保证任意外部Agent永不结束，也不能仅凭指令证明它确实正确理解；不以进程在线或搜满数量代替相关性验证。

## 3.37.1：工具自带常驻搜索脚本（历史，默认自动采集已由3.37.2取消）

- 此版曾以裸`--serve`默认启动采集脚本；它缺少模型理解与审核，3.37.2已禁用此默认路径。请使用上方当前接入方式。
- 自带脚本读取配置顶层 sources，按最新额度回推 candidate_ids，保留封面、时长及资源类型；每页立即交付，按服务器证据续页，等待登录时不结束接管。
- 没有结果也没有检索证据时，空 done 不再冒充成功完成。接管器与工作子进程记录启动、来源、页码、接收数及结束事件。
- 默认脚本使用工具站点适配器，不调用模型。语义改写、额外联网渠道仍需 Agent 提供相应能力，不能唤醒已结束的模型对话。

## 3.37.0：持续接管与实时额度（3.37.1起默认无需自编工作脚本）

- 模式切换不再撤销未满额的任务。已收20条时切到无限模式，原任务继续补980条；无限模式已收150条时切回限制模式，本轮立即完成，保留150条并等待下一轮。
- 同一批次的计数起点不因切换重置；100条已完成后切到无限模式，派发剩余900条。控制长轮询即时通知新额度，结果接收也按新额度执行。
- 运行助手新增 `--serve --run 通用工作命令`：工作程序完成后接管器继续等候新任务；任务文件实时同步额度，暂停不退出，主动断开才终止接管。
- 更新后重新复制接入指令。常驻接管器需要Agent提供能处理新关键词的通用工作脚本，不能复用写死旧task_id的脚本。它不含模型调用能力，不能唤醒已结束的模型对话；只写“继续待命”也不代表接管仍在执行。

## 3.36.3：连续空页不再无限续搜

- 区分“确认末页”和“本轮检索受限”。同一查询连续3个成功页没有新的候选链接、到第50页，或任务累计检查200页时，停止相应检索，不伪造网站已无资源。
- 已有结果保留；其他未完成来源继续检查。受限收尾后不自动补足、不消耗先前滚动动作；用户再次向下滚动可重试，100/1000条资源额度不变。
- 续搜建议一次推进每个平台的一个关键词，避免大量交替查询反复回收浏览器页；超过第50页的请求明确拒绝，不再返回第50页冒充新页。
- 更新后重新复制接入指令；Agent应检查pagination.limited与收尾响应search_limited，不自行重开任务绕过停止边界。

## 3.36.2：未完成任务不能凭不足说明提前结束（收尾边界由3.36.3补充）

- Agent报告资源不足时，工具核对本轮实际分页记录。尚有下一页、未检查来源或仍在运行的搜索时，保留原任务与结果，返回明确续搜要求。
- 再次轮询恢复同一个任务，保留原额度、已交付数、排除链接及页码；页面明确显示“已接收10/100，尚未完成”。真实末页及100/1000额度停止规则保留。
- 更新后需重新复制接入指令给Agent。外部AI客户端主动结束对话时，工具不能代它发起模型调用；不能把一段“待命中”文字当成真实运行中的轮询程序。

## 3.36.1：换词续搜复用登录

- 修复Agent交替查询多个关键词后，旧关键词续页被误判为需要再次登录的问题。各查询保留独立后台页面、游标和去重记录。
- 最多保留4个后台搜索页；旧页回收或关闭后，自动用当前存档的登录状态恢复该查询，并跳过已返回的资源。不会因此打开登录窗口。
- 网站确实退出登录或要求年龄验证时，仍正常提示用户完成官网操作。
- 修复静默后网络接口要求重新接管的遗漏；已授权Agent可以继续请求，无需因心跳时间过旧重复接入。

## 3.36.0：Agent持续接管与运行检测

- 已接管任务不再因长时间无结果、无进度或网络检测超过5分钟而自动撤销。工具周期检查状态，区分“搜索子程序仍运行”和“暂未收到心跳”；静默不再要求重新接管。
- 使用接入指令中的运行助手启动本地搜索脚本后，自动登记助手及搜索子程序；工具每2秒核对其存活和创建标识，不扫描其他程序。只有监听取消的后台脚本不算搜索活跃证据。
- 用户暂停、换词/来源、断开、明确失败或达到额度仍正常生效。更新后重新复制一次接入指令给Agent，才能让其使用新版运行助手；旧客户端的会话也不会仅因静默被撤销。
- 连接详情增加工具网络墙钟时间和工具外等待/执行时间。后者包括Agent思考、自行抓取、登录等待等，不能直接当作模型推理时间。接入指令优先复用工具候选，避免重复逐条访问已有可靠元数据的资源。

## 3.35.2：修复已登录续页请求

- 修复部分关键词触底只得到广告或假空页、重复重试仍无法继续的问题：已登录搜索改由后台网页自身加载下一页，读取真实搜索结果增量，不再手工拼接登录续页请求。
- 只缓存成功读取的页；失败、取消或换词不提交游标，重试可以重新取得新结果。仅根据实际网页进度确认结束，不把手工请求的空响应当成平台搜尽。
- 使用真实主界面及真实登录会话连续滚动验证，包括用户报错词。浏览器仍无界面运行，登录存档、封面和其他搜索方式保留。

## 3.35.1（历史，续页实现由3.35.2修正）：修复触底重复登录弹窗

## 3.35.0：登录一次，后台搜索

- YouTube需要登录时，工具打开当前本地存档专用的正常Edge/Chrome窗口。完成官网登录后点“已登录”，窗口自动关闭，搜索和触底续页转到无界面后台，不再同步显示网页或切换日常浏览器。
- 登录状态随本地用户名保存，重新打开工具可自动复用；不同用户名相互隔离。日常浏览器已有登录不会自动复制，首次需在专用窗口登录一次；登录过期或原站要求验证时再提示。
- 无需安装扩展、复制连接信息或额外开发环境。退出工具或切换存档会关闭工具自己的后台浏览器，保留登录资料，不关闭日常浏览器及其视频页面。
- 真实登录验证：24→45→64条，关闭重开工具后无需登录直接返回24条。另以三组普通关键词各验证两次后台续页，未新增浏览器窗口。当前此登录续搜流程适用于YouTube。

## 3.33.1（历史，默认流程已由3.35.0替代）：复用现有标签页，观看视频时继续搜索

- 正在播放视频，或原搜索页已被点成视频时，保留播放页面，复用已有同词搜索标签；没有时只在同一窗口准备一个后台搜索标签。触底继续读取搜索页后恢复原标签，不再直接报“已离开当前搜索”。

- 工具创建并复用自己的普通浏览器工作窗口，沿用该浏览器已有会话；不导出Cookie/密码，不操作账号输入框，不更改浏览器安全策略。优先后台滚动，必要时会短暂切换焦点；请保留工具工作窗口。
- 验证页直接复用于恢复搜索，避免重复打开同一页面。取消、换词会停止读取组件，退出只关闭工具标记的YouTube工作窗口，不关闭日常浏览器窗口。

## 3.32.0（历史，默认连接方式已由3.33.0替代）：登录后自动连接浏览器

- YouTube搜索遇到登录/年龄提示时，在常用Chrome、Edge等Chromium浏览器自行登录并保持页面打开，然后点击“已登录，继续搜索”。工具复用已授权会话；需要连接时自动在正在运行的受支持浏览器打开本机连接助手，不再要求粘贴连接信息。
- 首次仍需浏览器确认安装随附扩展一次；已安装旧版时需在扩展管理页重新加载，再刷新连接页。助手提供打开对应浏览器扩展管理页和复制安装目录的操作，安装后自动配对并继续验证。浏览器禁止静默安装，工具不修改其安全策略或用户资料。
- 弹窗显示连接/验证加载状态，成功才关闭并恢复该平台；跳过/换词/关闭使旧操作失效，其他平台继续。连接不等于登录成功，仍检查同一浏览器的实际搜索页。
- 当前浏览器登录续搜支持YouTube；不承诺任意网站自动首次登录、验证码处理、Firefox或未授权浏览器页面访问。有效会话可以复用，账号密码仍由用户在官网输入。

## 3.31.1：视频时长补全

- 修复部分YouTube结果只在缩略图角标或文本片段中提供时长、导致卡片漏显的问题。
- Agent或索引结果缺少时长时，可见区域的B站/YouTube视频会在后台尝试读取原站元数据，成功后更新右下角时长；无需重新搜索。
- 补全使用独立的两线程有界队列、链接去重、缓存和失败冷却；不等待补全就能展示和滚动。切换搜索后忽略旧回调，图片/文章不查询视频时长。平台未提供可靠时长时保持未知，不编造数据。

## 3.31.0：爱给音效只保留一个提取入口

- 移除爱给音效面板的“查看失败详情”“重新解析”和扩展可选区域。准备与失败恢复统一使用“一键打开并提取 / 一键重试”，实际错误直接显示在状态文字及悬停提示中。

网络助手使用 Python 的 [ProxyHandler](https://docs.python.org/3.12/library/urllib.request.html#urllib.request.ProxyHandler)；
访问本地接口显式绕过代理，不依赖宿主环境是否正确设置 `NO_PROXY`。

## 它能做什么

- **两种模式**：`直接搜索`（关键词直搜）和 `Agent 模式`（一键把接入指令交给本机 Agent，
  之后点搜索就把任务派给它；没接入时弹窗提示你粘贴，不会偷偷改成关键词搜索）。
- **一次搜索，多站并发**：默认内置哔哩哔哩、YouTube、必应、百度视频四个来源，可自由增删。
- **卡片墙看封面挑资源**：每张卡片有封面图、标题、来源、UP 主、时长角标、播放量，和视频网站列表一样。
- **筛选与排序**：按相关度 / 最新发布 / 播放最多排序，按时间（24 小时 / 本周 / 本月 / 今年）、
  播放量（1 万 / 10 万 / 100 万）过滤，结果可按来源分组。
- **点一下打开、右键复制**：单击卡片 = 浏览器打开；右键 = 打开 / 复制网址 / 复制标题 / 复制封面图。
- **自动解开跳转链接**：百度/必应那种 `xxx.com/link?url=...` 的跳转地址，复制时会自动解析成真实地址。
- **白名单 / 黑名单**：白名单是「必须去搜的站点」，黑名单是「禁止搜索的词」；命中黑名单会直接拒绝搜索，
  结果里也会过滤掉。
- **网络跟随本机**：判断依据是 Windows「系统代理」开关（和浏览器一致）。关掉 VPN（系统代理被关）时
  境外站点会失败、国内照常；打开 VPN 后点左下角「⟳ 刷新网络」即可。**每次打开会自动检测一次**，不用手动点。
- **搜索旁的 ⟳ 刷新按钮**：用当前关键词和筛选条件再搜一遍；正在搜时点它会先停掉这一轮再自动重搜。
- **无限下滑**：滚到最底下自动抓下一页，直到「已经到底了」
- **网络检测更准**：代理和直连同时试，哪个通道先用哪个，徽标显示实际通道和耗时
  重新检测并按当前网络自动配置访问方式。
- **不用装 Python**：交付物是免安装的文件夹版（`资源搜寻器.exe` + `_internal`），解压双击即用，
  配置和封面缓存都放在用户目录。

### Agent 模式（本机 AI 接管）

顶栏中间切到 `Agent 模式`，然后：

1. 点提示条上的 **「① 复制接入指令」** —— 剪贴板里是完整的接管说明
   （接口地址、token、工作流程、回推格式）。
2. 把剪贴板粘给你本机已经开着的 Agent（Claude / ChatGPT / Codex / DSH / Cursor
   这类能执行命令、能上网的工具），回车。它会开始「循环取任务」：
   ```http
   GET  http://127.0.0.1:8765/api/task?token=xxxxxxxx&wait=20&agent=Codex
   POST http://127.0.0.1:8765/api/results?token=xxxxxxxx
   {"task_id": "t3", "query": "用户原话", "done": false, "results": [{"title": "标题", "url": "https://..."}]}
   ```
3. 之后你在输入框里用大白话说要什么，点「AI 搜索」：任务会直接派给 Agent，
   由它去搜、去筛，搜完把结果推回来，卡片立刻出现在列表里。
   提示条会显示是谁在接管：「收件口已开启 · Codex 正在接管（3 秒前取过任务）」。
   点搜索后，**左边侧栏**会出现转圈的「正在让 Codex 搜索…」，不会挡住结果区，
   Agent 发 done:true 后自动消失；换词时搜索按钮仍可用。
   旁边的 **「⏸ 暂停」** 可以随时让它停手（Agent 取任务会看到 `paused=true`，
   推来的结果也不再入库），点「▶ 继续」接着搜下一轮。
   工具**不会自动扫描**你电脑上装了什么 Agent，全靠「复制 → 粘贴」接上。
4. **多个 Agent 时以最新的为准**：又粘了一份指令给另一个 Agent，新来的接管，
   旧的会收到「已被接管，请停止」并退出，提示条上的名字也跟着换。
5. **Agent 模式也能一直往下滑**：滚到最底下会自动给 Agent 派一条「要更多」的
   任务（会跳过已经给过的链接），限制模式每批最多 100 条，之后等待用户滚动；
   无限模式可自动续搜至本关键词最多 1000 条，资源耗尽也会提前结束。
   Agent 是**边搜边推**的：搜到一条就先 POST 一条（`done:false`），卡片一张张
   冒出来，侧栏显示「已收到 N 条，Agent 还在继续搜…」；这一轮收尾再发
   `{"task_id":"t3","done":true,"results":[]}`，圈圈才会停。
6. **换搜索词会立刻中断**：哪怕上一轮还在搜，也会马上停掉、清空旧结果，
   按新词重新派任务，不用等它搜完，也不会把两个词的资源堆在一起。
7. **Agent 失败必须回报**：它搜不到/被审核拒绝/报错时要 `POST /api/error`，
   工具会弹窗告诉你它报的是什么错；如果它既不回话也不报错，连续 150 秒没有结果或进度后弹
   「等待 Agent 超时」。
8. 没 Agent 接入时点「AI 搜索」**不会偷偷用关键词搜**，而是弹窗提醒：

   ![没有 Agent 接管时的提示](shots/exe-v131-agentwait.png)

   - 「我已粘贴，交给 Agent」= 保留任务，等 Agent 取；
   - 「仍用本地搜索」= 明确按关键词搜一轮（并提示这不是 Agent 结果）；
   - 直接关闭 = 取消，并撤掉队列里的任务。
   弹窗里的「重新检测」可以现场复查 Agent 有没有连上（90 秒内取过任务才算接入）。

换句话说：**这个工具本身可以是「展台 + 存放台」，搜索这件事交给接管的 Agent 干。**

> 黑名单在两种模式下都生效：关键词命中会直接拒绝搜索；
> Agent 推回来的结果也会按标题 / 简介 / 链接 / 作者过滤一遍再显示。

## 常见问题

**Q：某个站点一直 0 条 / 转圈？**
A：先单独取消勾选其它站点再试。B 站有频率限制，短时间内反复搜可能触发风控（界面会提示，稍等
恢复时间由站点决定，稍后手动重试）；YouTube 在国内需要代理，见下一条。

**Q：需要开代理吗？**
A：工具会自动跟随系统代理/环境变量（`HTTP_PROXY`）。开着 VPN/代理时 YouTube 能搜；B 站、必应
这些国内站点会优先直连，代理挂了也不影响。设置里也能强制「代理优先 / 只走直连」。

**Q：封面显示「无封面」？**
A：图片站防盗链或图床挂了。可以到设置里关掉「显示封面图」省流量，或清空封面缓存重试。

**Q：配置和缓存存在哪？**
A：配置 `%APPDATA%\ResourceFinder\config.json`；封面缓存 `%LOCALAPPDATA%\ResourceFinder\cache`。
如果这两个目录不可写（例如权限受限），会自动退回到 EXE 旁边的 `data\` 目录。删掉配置即恢复默认。

**Q：搜索结果会不会上传到什么地方？**
A：不会。所有请求都是本机直接发往各个站点，配置、历史、缓存全都只存在本机。

## 开发与打包

```bash
# 环境（Python 3.12）
python -m venv .venv
.venv\Scripts\python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt

python main.py                 # 直接运行源码
python tools\selftest.py       # 后端自检（含联网）
python tools\uitest.py         # 界面自动化验收（含点击复制、黑名单、主题）
python tools\shot.py -o shots\x.png --query 风景   # 无头截图
python tools\make_icon.py      # 生成 assets/app.ico
python tools\build.py --dir --output-dir .validation\版本\final-dist
python tools\package.py --dist-dir .validation\版本\final-dist
# 始终是 onedir 文件夹版，不提供单文件版；含存档的目录不能直接覆盖构建。
```

打包后如果打不开，可以让 exe 自己体检一次（窗口版没有控制台，结果写文件）：

```bat
资源搜寻器.exe --selftest --selfout selftest.txt
```

它会检查依赖、配置目录、网络、Qt 窗口能否创建，最后一行是 `RESULT: PASS` 或 `FAIL`。

app/engine.py            多站点并发搜索、去重、黑名单过滤
